# College Timetable Manager

## Project Statement

The **College Timetable Manager** is a Python-based application designed to help students easily manage and access their college timetable. The program allows users to view the complete timetable, check the timetable for a particular day, search for a subject, and add a subject to a selected day.

## Problem Statement

Students often need to check their timetable to find subjects scheduled on a particular day or period. This project provides a simple menu-driven system that makes accessing timetable information easier.

## Features

- View complete weekly timetable
- View timetable for a specific day
- Search for a subject
- Add a subject
- Simple menu-driven interface

## How It Works

The timetable is stored using a Python dictionary. Each day is used as a key and the subjects for that day are stored in a list.

Different functions are used for different operations:

- show_timetable() → Displays the complete timetable
- show_day() → Displays the timetable for a selected day
- find_subject() → Searches for a particular subject
- add_subject() → Adds a new subject

The program uses a menu-driven system so that the user can select the required operation.
